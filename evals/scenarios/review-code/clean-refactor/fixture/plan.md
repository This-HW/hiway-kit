# 계획: 리포트 목록 정리

## 목표
- `get_reports` 를 `list_reports` 로 이름을 바꾸고(호출부·테스트 포함) 분기 사슬을 조회표로 정리한다.
- CLI 의 크기 열을 사람이 읽는 이진 단위(`1.5 KiB`)로 보여 준다.
- 범위 밖 `--limit` 은 트레이스백 대신 사용법 오류로 끝낸다.

## 결정
- 정렬 열 이름은 바인드 파라미터가 될 수 없으므로 고정 조회표에서만 고른다. 입력 문자열을 SQL 에 넣지 않는다.
- 동점은 `id` 로 정렬해 페이지를 결정적으로 만든다.
- 페이지 기본값 20·상한 100 은 그대로 둔다(상수로만 빼서 CLI 와 함께 쓴다).
- `size_bytes` 는 스키마(`schema.sql`)가 `NOT NULL CHECK (typeof(size_bytes) = 'integer' AND size_bytes >= 0)` 으로 보장한다(기존 스키마, 이 변경에서 바꾸지 않음).
- `reports` 모듈은 이 저장소의 `cli.py` 만 import 한다(배포 패키지 아님) — 옛 이름 별칭을 남기지 않는다.
- CLI 출력은 사람이 터미널에서 읽는 용도다. 이 출력을 파싱하는 기계 소비자는 없다(저장소 전체 검색으로 확인).
