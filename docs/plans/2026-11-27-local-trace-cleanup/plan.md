## 요구사항

- 현재 추적 트리에서 개인 홈 경로, 도구 캐시와 설치 절차를 정리한다. 제품 사용 안내, 측정 결과, 릴리스 기록은 보존한다.
- Archify 도식에는 재생성에 필요한 버전과 명령을 남긴다. Hermes 측정 프로필은 호출자가 전달한 실제 홈을 보호한다.

## 결정

- 사용자 요청에 따라 기존 커밋과 플러그인 배포물을 보존한다. 문서와 레포 전용 검사만 바뀌므로 버전은 유지한다.
- 로컬 완료 검사와 CI에서 같은 스크립트로 Git 추적 텍스트를 검사한다. 예외는 저장소 내부 파일의 특정 줄에만 사유와 함께 허용한다. 위반 출력에는 파일, 줄, 패턴 분류를 담는다.

## 구현 계획

1. 추적 문서의 개인 경로를 제거하고 샌드박스 호출에 호스트 홈을 전달한다.
2. 새 CLI 테스트의 실패를 확인한 뒤 검사와 예외 정책을 구현하고 로컬 게이트와 CI에 연결한다.
3. 샌드박스 허용·거부와 게이트의 실패·복구를 실측한 뒤 전체 검사를 실행한다.

## 완료 조건

- 추적 문서에 개인 경로 한 줄을 추가해 스테이징하면 `python3 scripts/check_local_traces.py`는 rc 1, 복구 뒤에는 rc 0을 반환한다.
- macOS에서 프로필의 허용 디렉터리 쓰기는 rc 0, 그 밖의 쓰기와 호스트 홈 읽기는 거부된다.
- `python3 -m pytest scripts/tests -q`, `./scripts/verify-done.sh`, `git diff --quiet origin/main -- plugins/common`이 각각 rc 0을 반환한다.

## 검증 결과

- 추적 파일에서 조사 대상 문자열은 0건이었다. 새 검사는 예외 없이 텍스트 643개를 확인했다. 문서에 테스트 경로를 스테이징한 상태에서는 파일명·줄 번호·분류를 출력하고 rc 1, 복구 뒤에는 rc 0을 반환했다.
- 새 CLI 테스트 23건에서 구현 전 실패와 구현 후 통과를 확인했다. 예외를 심링크에 붙여 다른 파일까지 가리는 경우, 파일명에 포함된 경로가 진단에 노출되는 경우도 확인했다.
- Hermes 프로필은 두 네트워크 모드 모두에서 픽스처 파일 생성을 허용했다(rc 0). 허용 범위 밖의 파일 생성과 실제 홈의 파일 읽기는 각각 rc 1이었다.
- 전체 게이트 43 pass / 0 fail. 스크립트 테스트 전체와 플러그인 트리 대조도 각각 rc 0이었다.
